4. **预算耗尽的对外形态**：运行先置 `FAILED` 并落遥测（可审计），再对外抛
   `BIZ_422_LLM_BUDGET_EXHAUSTED`（§11.8）；避免「运行已失败但调用方收到成功响应」。
